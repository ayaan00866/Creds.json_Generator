WhatsApp Pairing

Code ya QR se link karo, creds.json aapke WhatsApp par aa jayega.

Aapka pairing code
  1. WhatsApp kholo, Settings > Linked devices
  2. "Link with phone number instead" dabao, phir code daalo
  3. Camera se ye QR scan karo

creds.json se poora account access hota hai. Ise kisi ke saath share mat karo. Ye tool sirf apne number ke liye use karo.
